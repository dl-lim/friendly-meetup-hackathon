To get a specific event:

```bash
git clone -b <branch-name> https://github.com/dl-lim/friendly-meetup-hackathon.git
```

P.S. Yes, we know this isn't how branches are meant to work. These branches will never merge, never rebase, and never speak to each other. Each one is its own little universe. Please don't open a PR to main – there's nothing here but this README, and it likes it that way.
